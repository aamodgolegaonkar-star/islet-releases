# Islet

A Dynamic Island for your Mac, in Liquid Glass: now playing, synced lyrics, a full-screen player and a lock-screen widget. Works with Apple Music and Spotify.

## Install

1. Download **Islet.dmg** from the [latest release](https://github.com/aamodgolegaonkar-star/islet-releases/releases/latest).
2. Open it and drag **Islet** into **Applications**.
3. Open Islet once. macOS will say it can't verify the app, because it isn't notarized by Apple. Click **Done**.
4. Go to **System Settings → Privacy & Security**, scroll down, and click **Open Anyway** next to Islet.

You only need to do that once. After that, Islet updates itself.

Requires an Apple-silicon Mac on macOS 26 or later.
